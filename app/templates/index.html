Rate Limit Guidelines (Google AI Studio Official):
• Free Tier (15 RPM limit): Set Simultaneous Videos to 1 to stay safely within Google's 15 requests/minute free threshold.
• Pay-As-You-Go / Tier 1 (300+ RPM limit): Set Simultaneous Videos to 3 (or higher) to translate entire seasons in parallel at ultra-speed.
Tip: Flash-Lite and Flash start at 300 RPM on Tier 1 (scaling up to 1,000+ RPM as usage grows), while Pro models have stricter limits (150 RPM).
OpenAI Rate Limit Guidelines:
• Tier 1+ Account: Set Simultaneous Videos to 2. GPT-4o Mini is fast and cost-effective for subtitle translations.

Features & Modules

Enable or disable subtitle extraction and processing modules.

SDH & Noise Cleaner

Automatically cleans SDH sound descriptions, background noise, and musical notes while maintaining flawless sync.

Extract Embedded Target Subtitles

If target language already exists inside the video, extracts it directly as an external .[lang].srt file.

Extract Embedded Source Subtitles

Extracts embedded English subtitles from MKV/MP4 as source (Priority 1 for best sync accuracy).

Auto-Repair Corrupted Subtitles

Inspects existing subtitles and re-translates if severe sync or line corruption is detected.

Strict Source Sync Lock

Locks start and end timestamps directly to the source subtitle timing.

Original Language Guard

Prevents AI translation if the video's primary audio already matches your target language. Protects domestic movies from bad round-trip translations.

Integrations & Pipeline Mode

Choose how Babel handles subtitles: Hybrid Mode with Bazarr, or Pure AI Direct.

Hybrid Mode

Parallel Prep + Bazarr Coordination

Babel checks for human subtitles through Bazarr while preparing the AI fallback. If no target subtitle is available when preparation completes, translation starts immediately.

Pure AI Mode

Instant 0s Delay / AI First

Babel extracts embedded tracks and translates immediately, bypassing Bazarr searches entirely. Runs completely standalone (no external dependencies).

Bazarr Integration Parameters
Zero-Wait Hybrid: Bazarr searches for human subtitles concurrently while Babel prepares the AI fallback. No fixed delay window.

Plex Media Server

Scan the matching Plex library when a new subtitle is ready

Only needed when Plex sees your media under a different path than Babel does. Leave blank if both use the same paths.

Webhooks & Arr Automation

Sniper-Webhook URLs to trigger Babel automatically when Sonarr or Radarr finishes a download.

Sonarr Webhook Endpoint POST
Inside Docker network you can also use: http://babel:8765/webhook/sonarr
Radarr Webhook Endpoint POST
Inside Docker network you can also use: http://babel:8765/webhook/radarr
How to set up in Sonarr / Radarr:
1. Go to Settings → Connect → click + → select Webhook.
2. Name: Babel.
3. Check triggers: On Download and On Upgrade.
4. URL: Paste the copied endpoint above (e.g. http://babel:8765/webhook/sonarr?secret=your_secret_here).
5. Method: POST → Click Test (will show green checkmark) → Save.
