# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Babel, please DO NOT disclose it publicly on the issue tracker.

Options for reporting:
- **GitHub Security Advisories:** If enabled on this repository, please use the private vulnerability reporting feature on GitHub.

## Best Practices
- Never post API keys, system paths, or credentials in public issues.
- Security-related issues should be reported carefully to avoid leaking private details.
- When sharing logs, ensure all tokens and passwords are redacted.
